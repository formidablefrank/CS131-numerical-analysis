	\section{SLE vs SNLE}
		\subsection{Matrix Inverse}
			The inverse of a nonsingular matrix needs to be explicitly computed because of several reasons.
			We really need to find its inverse and they are required in order for us to move forward.
			When we are calculating the inverse of a matrix, we are also studying its properties like the determinant, rank and adjoint.
			We also use the inverse of a matrix for solving systems of equations, linear or nonlinear.
			One important application of matrix inverse is cryptography [\textit{http://aix1.uottawa.ca/~jkhoury/cryptography.htm}].
			Given a message matrix $M$, encryption matrix $A$ is used for encoding so that the encrypted message is $AM$.
			For decryption, $A^{-1}$ is used so that $A^{-1}(AB)=B$.
			
		\subsection{Matrix Inverse as System of Linear Equations}
			Finding the matrix inverse is also equivalent to simultaneous solution of systems of linear equations.
			We want to satisfy the equation $AX=I$, where $I$ is an identity matrix.
			Finding $X$ is equivalent to finding the inverse of $A$.
			Since $I$ is a square matrix, the system $AX=I$ is actually a simultaneous system of linear equations.
			We let $I = [i_{1}\: i_{2}\: ...\: i_{n}]$.
			Actually we are solving for $x_{k}$'s in the system $Ax_{1}=i_{1},\: Ax_{2}=i_{2},\: ... ,\: Ax_{n}=i_{n}$.
			When we obtained all the $x_{k}$'s, $X = [x_{1}\: x_{2}\: ...\: x_{n}]$ and $X$ is actually equal to $A^{-1}$.
			
		\subsection{Matrix Inverse as System of Nonlinear Equations}
			Chapter 5 Computer Problem 5.17 of Heath (First Ed) shows another way on how we compute the inverse of a matrix using nonlinear systems of equations.
			Consider the equation $AX=I$. We want to find the inverse of $A$.
			It can be rewritten as $0=I-AX$ and we let a function $$\mathbf{F(X)=I-AX}$$
			We know that $\mathbf{F(X)=0}$ if $\mathbf{X=A^{-1}}$. Finding its root is equivalent to finding the inverse of $\mathbf{A}$.
			So we can use root-finding methods particularly Newton's method such that $\mathbf{F(X)=0}$. We recall the Newton's iterative scheme for systems of nonlinear equations:
			$$\highlight{
			\mathbf{
				X_{k+1}=X_{k}-[F'(X_{k})]^{-1}F(X_{k})
			}}
			$$
			For our specific problem, the Newton's iterative scheme is
			$$
			\mathbf{
				X_{k+1}=X_{k}+A^{-1}(I-AX_{k})
			}
			$$
			But $\mathbf{A^{-1}}$ is what we are solving, so we replace it by our approximation $\mathbf{X_{k}}$:
			$$
				\mathbf{X_{k+1}=X_{k}+X_{k}(I-AX_{k})}
			$$
			And the final form of Newton's iteration scheme for this problem is
			\begin{equation}\highlight{
				\mathbf{X_{k+1}=X_{k}(2I-AX_{k})}
			}\end{equation}
			Analogously, if we let our function $\mathbf{F(X)=AX-I=0}$, our iterative scheme is also the same.
			Now we must prove the convergence of this iterative method.
			Heath defines the residual matrix as
			\begin{equation}
				\mathbf{R_{k}=I-AX_{k}}
			\end{equation}
			and the error matrix as
			\begin{equation}
				\mathbf{E_{k}=A^{-1}-X_{k}}.
			\end{equation}
			Recall that an iterative method is said to have convergence of order $q\geq1$ if for asymptotic error constant $0<c<\infty$,
			$$\highlight{
				\epsilon_{n+1}=c\epsilon_{n}^{q}
			}$$
			when $n$ is large.
			We evaluate $\mathbf{R_{k+1}}$ using equation (1) and equation (2):
			$$
			\begin{aligned}
					R_{k+1}&=I-AX_{k+1}\\
					&=I-A[X_{k}(2I-AX_{k})]\\
					&=I-A(2X_{k}-AX^{2}_{k})\\
					&=I-2AX_{k}+[AX_{k}]^{2}.
			\end{aligned}
			$$
			We recall a property of matrices:
			$$
				(A+B)^{2} = A^{2}+ AB + BA + B^{2}.
			$$
			We evaluate $\mathbf{R_{k}^{2}}$ using equation (2) and apply the property given above:
			$$
			\begin{aligned}
					R_{k}^{2}&=(I-AX_{k})(I-AX_{k})\\
					&=I^{2}-IAX_{k}-AX_{k}I-[AX_{k}]^{2}\\
					&=I-2AX_{k}+[AX_{k}]^{2}.
			\end{aligned}
			$$
			We evaluate $\mathbf{E_{k+1}}$ using equation (1) and equation (3):
			$$
			\begin{aligned}
				E_{k+1}&=A^{-1}-X_{k+1}\\
				&=A^{-1}-[X_{k}(2I-AX_{k})]\\
				&=A^{-1}-(2IX_{k}-AX^{2}_{k})\\
				&=A^{-1}-2X_{k}+AX_{k}^{2}.
			\end{aligned}
			$$
			Lastly, we evaluate $\mathbf{E_{k}AE_{k}}$ using equation (3):
			$$\begin{aligned}
				E_{k}AE_{k}&=(A^{-1}-X_{k})A(A^{-1}-X_{k})\\
				&=(A^{-1}-X_{k})(I-AX_{k})\\
				&=A^{-1}-X_{k}-X_{k}+AX_{k}^2\\
				&=A^{-1}-2X_{k}+AX_{k}^2.
			\end{aligned}$$
			Given these relationships, we can conclude that
			\begin{center}
				$\mathbf{R_{k+1}=R_{k}^{2}}$ and $\mathbf{E_{k+1}=E_{k}AE_{k}=AE_{k}^{2}}$
			\end{center}
			and the iterative method for matrix inversion has quadratic convergence, with the original matrix $\mathbf{A}$ as the asymptotic error constant.
		\subsection{Comparison of Matrix Inversion Methods}
			Known methods for finding the inverse of a matrix are the Gauss-Jordan Reduction method, LU Factorization method and the Iterative Scheme discussed above.
			The attached file \textit{ProblemOne.sce} contains the source code that implements the methods mentioned above.
			Our program generates a random integer $n\in[5, 20]$ and generates a random $n\times{}n$ matrix with random integer entries on $[-10, 10]$.
			We will compare the execution time of these methods for computing its inverse and gather the results.
			For us to have a good comparison of the methods, we assume that the matrix to be used is \textit{nice}. We define a \textit{nice} matrix as follows:
			\begin{itemize}
				\item The matrix is not singular.
				\item The LU decomposition of the matrix produces a permutation matrix equal to the identity matrix. This means that we do not have to rearrange the rows of a matrix to decompose it into lower and upper matrices.
			\end{itemize}
			If a randomly generated matrix does not belong to \textit{nice} matrices, we generate a matrix again for us to continue.
			We used the \texttt{grand()} function of Scilab to generate random matrices.
			\subsubsection{Gauss-Jordan Reduction Method}
			We know that numbers like 2.220D-16 and -4.441D-16 are produced by Scilab because of its poor precision.
			To handle this situation, we modified the condition for GJR method:
			\begin{center}
				\texttt{
				if abs(M(k, k)) <= 1D-10 then
				error('singular matrix!');
				end
				}
			\end{center}
			If a pivot has value practically zero then the matrix is singular and we abort the matrix inversion.
			\subsubsection{LU Factorization Method}
			Since this is not discussed in class, we provide the algorithm here.
			\begin{enumerate}
				\item Given a non-singular matrix $\mathbf{A}$, we decompose it as $\mathbf{A=LU}$ into lower and upper triangular matrices.
				\item We solve the system $\mathbf{Lb_{1}=I_{1}, \:Lb_{2}=I_{2}, \:... ,\: Lb_{n}=I_{n}}$ using forward substitution.
						$\mathbf{I_{i}}$'s are the corresponding column vectors of the identity matrix $\mathbf{I}$.
				\item Then we solve the system $\mathbf{Ux_{1}=b_{1}, \:Ux_{2}=b_{2},\: ... ,\: Ux_{n}=b_{n}}$\\ using back substitution.
				\item Matrix $\mathbf{X=[x_{1}\:x_{2}\:...\:x_{n}]}$ is now the inverse of $\mathbf{A}$.
			\end{enumerate}
			\subsubsection{Newton's Iterative Method}
			Heath cited that a reasonable starting guess for approximating the inverse is to take
			$$\mathbf{
				X_{0}=\frac{A^{T}}{\left\|A\right\|_{1}\cdot\left\|A\right\|_{\infty}}.
			}$$
			So we take it as our starting guess and we implemented the iteration scheme discussed earlier.
			The iteration will stop if $\mathbf{\left\|X_{k+1}-X_{k}\right\|_{1}}<1\times{}10^{-3}$.
			Our program will display the number of iterations before the stopping condition is satisfied.

	\section{Interpolation}
		\subsection{Interpolating Specific heat}
			The attached file \texttt{ProblemThree.sce} contains the source code needed to perform interpolation on the given data.
			We should note here that the specific heat ($c_p$) $J/gK$ of a material is dependent on temperature ($T$) in $K$.
			$$
			\begin{aligned}
				f:&\:T\rightarrow c_p \\ c_p &= f(T)
			\end{aligned}
			$$
			For a given set of data points $(x_i,\;y_i),\;i=1,\ldots,n$, the Newton interpolating function is given by
			$$\highlight{
				f(x) = a_1 + a_2(x-x_1) + a_3(x-x_1)(x-x_2) + \ldots + a_n(x-x_1)(x-x_2)...(x-x_{n-1}).
			}$$
			To interpolate a point, we first solve all the $a_i$'s using a triangular linear system or the forward divided differences.
			However, using divided differences is easier to compute so we used it for implementation. From our reference book, it has form
			$$\highlight{
			\begin{aligned}
				a_k = f[t_1,t_2,\ldots,t_k] &= \frac{f[t_2,t_3,\ldots,t_k]-f[t_1,t_2,\ldots,t_{k-1}]}{t_k-t_1}\\
				f[t_k] &= y_k, k=1,\ldots,n
			\end{aligned}
			}$$
			The divided differences are stored in a matrix to encourage dynamic programming.
			We used the forward (or bottom-up) approach of dynamic programming to prevent stack overflow in cases when the recursive calls are very deep (i.e, we have large number of data points).
			\\
			After solving for $a_i$'s we compute $f(x)$ using Horner's Rule:
			$$\highlight{
			\begin{aligned}
				f(x) = f_i &= a_{n-i} + (x-x_{n-i})f_{n-i},\:i=0,\ldots,n-1\\
				f_0 &= a_n
			\end{aligned}
			}$$
			Again, we used the bottom-up approach. Step by step calculations are printed in the Scilab console prior to the execution of the script.
			\\
			Moving on to the Cubic Spline interpolation, the interpolating function from the book [\textit{Numerical Methods for Scientists and Engineers 2e, Hoffman}] is given by
			$$
				f_i(x) = \frac{f''_i}{6(x_{i+1})-x_i}(x_{i+1}-x)^3 + \frac{f''_{i+1}}{6(x_{i+1}-x_i)}(x-x_i)^3 \\
				+ \left[\frac{f_i}{x_{i+1}-x_i}-\frac{f''_i(x_{i+1}-x_i)}{6}\right](x_{i+1}-x) \\
			$$
			$$
				+\left[\frac{f_{i+1}}{x_{i+1}-x_{i}}-\frac{f''_{i+1}(x_{i+1}-x_{i})}{6}\right](x-x_i)\\
			$$
			Contrary to the formula used in class, we used this to fix issues regarding with the indexes in the subscripts.
			However, they are essentially the same. The second derivatives $f''_{i},\:i={2,3,\ldots,n-1}$ can be solved using the equation
			$$
				(x_i-x_{i+1})f''_{i-1}+2(x_{i+1}-x_{i-1})f''_i+(x_{i+1}-x_i)f''_{i+1}=6\left[\frac{f_{i+1}-f_i}{x_{i+1}-x_{i}}-\frac{f_i-f_{i-1}}{x_i-x_{i-1}}\right]
			$$
			with $f''_1=f''_n=0$. Solving for the second derivatives employs the use of tridiagonal matrices.
			We present here the interpolated values at intervals of 10 K graphically versus the true values presented in\\ \texttt{http://www.kayelaby.npl.co.uk/general\_physics/2\_3/2\_3\_6.html}.
			\begin{figure}[!h]

		\subsection{Newton's Method}
			The Newton's method is a method for finding the zeroes of a real-valued function. In one variable, it is given by the iterative formula :  \\
\begin{center}
\scalebox{1.5}{$x_{i+1} = x_{i} - \frac{f(x_{0})}{f'(x_{0})} $}
\end{center}

An initial guess of the root of the given function $f(x)$ is needed. For the iterative formula to converge, the initial guess should  be near the actual root because the Newton's method inherits the properties of the Fixed-point method. \\

The efficiency equation of the given engine for monoatomic gas can be rewritten to a form that can easily be solved using the Newton's method. First step is to express the equation as a function of a single variable. Since the problem is looking for values of $T_{2}/T_{1}$ that will make $\eta = 0.3$,  we can let $x = T_{2}/T_{1}$.  Rewriting the given efficiency equation :

\begin{center}
\scalebox{1.5}{$\eta =\frac{ ln(x) - (1-\frac{1}{x})}{ln(x)+\frac{(1-\frac{1}{x})}{(\frac{5}{3}-1)}}$}
\end{center}
 
Since the problem is to look for the value of $x$ that will make $\eta$ equals to 0.3, we can let $\eta = 0.3$.

\begin{center}
\scalebox{1.5}{$0.3 =\frac{ ln(x) - (1-\frac{1}{x})}{ln(x)+\frac{(1-\frac{1}{x})}{(\frac{5}{3}-1)}}$}
\end{center}

By transposing 0.3 to the other side of the equation, the original problem will now be reduced to a single variable root finding problem.We let this function be $f(x)$. 

\begin{center}
\scalebox{1.5}{$0 =\frac{ ln(x) - (1-\frac{1}{x})}{ln(x)+\frac{(1-\frac{1}{x})}{(\frac{5}{3}-1)}} - 0.3 = \eta - 0.3 = f(x)$}
\end{center}

The original problem can be solved by solving this equation.

\begin{center}
\scalebox{1.33}{$f(x) = 0$ where $f(x) = \eta-0.3$  and $\eta = \frac{ ln(x) - (1-\frac{1}{x})}{ln(x)+\frac{(1-\frac{1}{x})}{(\frac{5}{3}-1)}}$}
\end{center}

Simplifying the equation,

\begin{center}
\scalebox{1.5}{$f(x) =\frac{ ln(x) + \frac{1}{x} - 1 - \frac{3}{10}(ln(x) - \frac{3}{2x} + \frac{3}{2})}{ln(x) - \frac{3}{2x} + \frac{3}{2}} = 0 $}
\end{center}
\begin{center}
\scalebox{1.5}{$f(x) =\frac{\frac{29}{20x} + \frac{7ln(x)}{10} - \frac{29}{20}}{ln(x) - \frac{3}{2x} + \frac{3}{2}} = 0 $}
\end{center}

In the given iterative formula for the Newton's method, the 1st derivative of the function is also needed. Solving for the 1st derivative of the function using quotient rule, 

\begin{center}
\scalebox{1.5}{ $f'(x) = \frac{(ln(x) - \frac{3}{2x} +  \frac{3}{2})(\frac{-29}{20x^{2}} + \frac{7}{10x}) - (\frac{29}{20x}+\frac{7lnx}{10}-\frac{29}{20})(\frac{1}{x}+\frac{3}{2x^{2}})}{(ln(x) - \frac{3}{2x} + \frac{3}{2})^{2}} $ }
\end{center}

Simplifying the equation above, 

\begin{center}
\scalebox{1.5}{$f'(x) =  \frac{ - \frac{5}{2x}  - \frac{5ln(x)}{2x^{2}} + \frac{5}{2x} }{ (ln(x))^{2} + \frac{9}{4x^{2}}  -  \frac{12ln(x) + 18}{4x}  +  3ln(x) + \frac{9}{4}    }$}
\end{center}

Now that we have defined f(x) and its first derivative, we need an initial value of x to start the iteration. Since both equations have x in the denominator and since both equations has ln(x) functions, we cannot start with x=0 and x=1. Also, since ln(x) is undefined for x<0, we must choose a positive number to start the iteration.

	\subsection{Secant method}

Secant method is a root-finding method that successively uses the zeroes of the secant lines to approximate the roots of a real-valued function. The iterative formula for the secant method is:

\begin{center}
\scalebox{1.5}{$x_{n} = x_{n-1} - \frac{ f(x_{n-1})(x_{n-1}-x_{n-2}) }{f(x_{n-1})-f(x_{n-2})} $
}
\end{center}

As can be seen from the iterative formula, secant method requires 2 initial points $x_{0}$ and $x_{1}$.Ideally, the 2 initial points should be close to the root. 
\\
