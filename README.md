# CS131 Numerical Analysis

## Description

I took a course on numerical analysis focusing on computational methods for solving mathematical problems involving systems of equations, root finding, and numerical integration. This repository contains problem sets, implementations, and mathematical analyses translating complex mathematical concepts into practical computational solutions.

## Learning Objectives

Through this coursework, I developed skills in:
- Solving system of linear and nonlinear equations (Gaussian elimination, Gauss-Jordan reduction, LU factorization)
- Root-finding (Newton's method, Regula-Falsi, bisection methods)
- Numerical integration and differentiation (Simpson's rule, composite quadrature, Gauss-Laguerre quadrature)
- Interpolation (polynomial interpolation, cubic spline interpolation)
- Matrix computation and stability analysis
- Convergence analysis and error estimation

I understand how to select appropriate numerical methods based on the problem, implement them with consideration for floating-point precision and convergence behavior, and conduct rigorous mathematical analysis of computational results.

## Problem Sets

**Problem Set 1: Systems of Linear and Nonlinear Equations**
- Matrix inversion via Gauss-Jordan reduction and LU factorization
- Iterative matrix inversion using Newton's method
- Comparative analysis of multiple algorithms
- Improving numerical stability

**Problem Set 2: Root Finding and Numerical Integration**
- Value-at-Risk (VaR) computation using Gaussian and t-distribution functions
- Root finding with Regula-Falsi and other methods
- Numerical integration with composite Simpson's rule and Gauss-Laguerre quadrature
- Applications to probability and financial mathematics

**Additional Topics:**
- Interpolation methods and their applications
- Numerical stability and precision handling in floating-point arithmetic

## Software Stack

- Scilab (scientific computing and numerical analysis)

To reproduce the results, I implemented all algorithms from scratch in Scilab, documenting each mathematical step and verifying convergence behavior through computed examples.
