# CS131: Numerical Analysis

## Description

I completed a comprehensive numerical analysis course focusing on computational methods for solving mathematical problems involving systems of equations, root finding, numerical integration, and advanced computational techniques. This repository contains problem sets, implementations, and mathematical analyses demonstrating proficiency in translating complex mathematical concepts into practical computational solutions.

## Technical Skills and Learning Objectives

Through this coursework, I developed expertise in:

**Core Competencies:**
- Linear and nonlinear equation solving (Gaussian elimination, Gauss-Jordan reduction, LU factorization)
- Root-finding algorithms (Newton's method, Regula-Falsi, bisection methods)
- Numerical integration and differentiation (Simpson's rule, composite quadrature, Gauss-Laguerre quadrature)
- Interpolation techniques (polynomial interpolation, cubic spline interpolation)
- Matrix computation and numerical stability analysis
- Convergence analysis and error estimation

**Learning Outcomes:**
I understand how to select appropriate numerical methods based on problem characteristics, implement them with consideration for floating-point precision and convergence behavior, and conduct rigorous mathematical analysis of computational results.

## Coding Exercises and Problem Sets

**Problem Set 1: Systems of Linear and Nonlinear Equations**
- Matrix inversion via Gauss-Jordan reduction and LU factorization
- Iterative matrix inversion using Newton's method
- Comparative performance analysis of multiple algorithms
- Implementation of numerical stability improvements

**Problem Set 2: Root Finding and Numerical Integration**
- Value-at-Risk (VaR) computation using Gaussian and t-distribution functions
- Root finding with Regula-Falsi and other bracketing methods
- Numerical integration with composite Simpson's rule and Gauss-Laguerre quadrature
- Applications to probability and financial mathematics

**Additional Topics Covered:**
- Interpolation methods and their applications
- Numerical stability and precision handling in floating-point arithmetic

## Software Stack

- Scilab (scientific computing and numerical analysis)

## Usage

The repository contains:
- `ProblemSet1/`: Scilab implementations of matrix computation methods with performance benchmarks
- `ProblemSet2/`: Root-finding and numerical integration implementations with financial applications
- `*.sce`: Scilab scripts demonstrating algorithms and computational results
- PDF files: Problem statements, mathematical derivations, and detailed results

To reproduce the results, I implemented all algorithms from scratch in Scilab, documenting each mathematical step and verifying convergence behavior through computed examples.
